About the data. Every figure in this series is a verbatim extraction from the enacted South Carolina General Appropriations Acts, processed through the Palmetto ZBB Suite — a line-item budget analysis platform covering all 115 state agency sections, with each amount traceable to its source page. Issues drawing on state expenditure data instead use the Comptroller General's Monthly State Spending Transparency Files, with the classification rules published alongside the issue. Analysis is deterministic: all arithmetic is computed directly from the extracted data, never estimated.
